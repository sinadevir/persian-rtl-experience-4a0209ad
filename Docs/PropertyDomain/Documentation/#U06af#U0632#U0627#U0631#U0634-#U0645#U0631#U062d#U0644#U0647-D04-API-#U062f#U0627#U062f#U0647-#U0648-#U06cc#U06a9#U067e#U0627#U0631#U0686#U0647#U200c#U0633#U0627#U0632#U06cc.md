# گزارش اجرای D04 ـ مستندات API، فرهنگ داده و قراردادهای یکپارچه‌سازی

## محدوده اجرا

در این مرحله فقط مستندات پروژه نسخه 11.8 تغییر کرده‌اند. کد اجرایی، منطق دامنه، مدل EF، Migrationها و داده‌ها تغییر نکرده‌اند.

## خروجی‌ها

1. `Docs/API/کاتالوگ-API.md` ـ فهرست 200 مسیر یکتای API استخراج‌شده از Endpointها و Program؛ شامل پارامترهای مسیر/Query/بدنه، نتایج HTTP قابل مشاهده و ارجاع فایل/خط منبع.
2. `Docs/DataDictionary/فهرست-جداول-و-ستون‌ها.md` ـ فهرست 74 DbSet و 74 نگاشت `ToTable`؛ 68 جدول در Baseline و 6 جدول افزوده‌شده در Migrationها؛ ستون‌ها، نوع SQL، تهی‌پذیری، قیود و فهرست‌ها استخراج شده‌اند.
3. `Docs/Integration/کاتالوگ-قراردادهای-یکپارچه‌سازی.md` ـ پوش پیام، پیام‌های خروجی ثبت‌شده، مسیر‌یابی، تحویل، Idempotency، Retry و موارد خارج از قرارداد.
4. چهار سند قرارداد حوزه B03، B04، B06 و B07 به فارسی بازنویسی شده‌اند و نام‌های فنی/فیلدهای JSON حفظ شده‌اند.

## یافته‌های مهم و محدودیت‌های صریح

- تعداد `DbSet` و نگاشت مستقیم `ToTable` در DbContext برابر 74 است. Baseline یکپارچه 68 جدول را به‌صورت CREATE TABLE دارد؛ با شش جدول افزوده‌شده از طریق Migrationها، تعداد کل جدول‌های دارای DDL در منابع بررسی‌شده 74 است.
- فهرست API مسیرهای ثبت‌شده را پوشش می‌دهد؛ این سند جایگزین OpenAPI تولیدشده در زمان اجرا و تعریف کامل تمام فیلدهای DTO نیست. نوع‌های مرتبط و فایل/خط منبع در کاتالوگ آمده‌اند.
- از نام رویداد داخلی به‌تنهایی انتشار Outbox استنتاج نشده است؛ نگاشت انتشار از `DomainEventOutboxBridge` و فراخوانی‌های مستقیم Outbox استخراج شده است.
- برای B03 چرخه تأیید/اجرای PropertyStructureChange قرارداد پیام تعریف نشده؛ برای B04 مصرف‌کننده تعرفه/صورتحساب یا Timeline مشترک B07 فرض نشده است.
- نام ستون‌ها و نوع SQL از DDL/Migration استخراج شده‌اند؛ شرح معنایی کسب‌وکاری ستون‌ها در موارد فاقد تعریف رسمی به‌صورت حدسی تکمیل نشده است.

## فایل‌های مرجع بررسی‌شده

- `Program.cs`، `Infrastructure/PropertyDomainDbContext.cs`، `Infrastructure/HttpTenantContext.cs`، `Middleware/ExceptionHandlingMiddleware.cs`.
- تمام فایل‌های `Modules/*/Endpoints/*.cs`.
- `Domain/Events/*.cs`، `Infrastructure/DomainEvents/DomainEventOutboxBridge.cs`، `Infrastructure/Integration/OutboxWriter.cs` و `OutboxDispatcher.cs`.
- `Database/PropertyDomain-Baseline.sql` و `Database/PropertyDomain-Migrations.sql`.
- قراردادهای پیشین B03/B04/B06/B07 که در این مرحله به فارسی بازنویسی شده‌اند.

## وضعیت زبان مستندات

اسناد جدید D04 و چهار قرارداد یکپارچه‌سازی حوزه‌ای به فارسی نوشته/بازنویسی شده‌اند. برخی گزارش‌های تاریخی پیاده‌سازی، اسناد اولیه منبع و تعدادی از مستندات قدیمی خارج از محدوده این مرحله هنوز انگلیسی یا ترکیبی هستند؛ برای حفظ قابلیت ردیابی، در این مرحله محتوای تاریخی منبع بازنویسی نشده است. یکسان‌سازی زبان آن‌ها باید در مرحله پاک‌سازی مستندات تاریخی انجام شود.

## موارد خارج از محدوده D04

- تولید OpenAPI/Swagger JSON یا اجرای سرویس برای واکشی قرارداد Runtime انجام نشده است.
- هیچ Migration یا SQL روی پایگاه داده اجرا نشده است.
- Build و آزمون‌ها اجرا نشده‌اند.
- اعتبارسنجی زنده مقصدهای HTTP، کلیدهای یکپارچه‌سازی و رفتار واقعی مصرف‌کنندگان انجام نشده است.

## نتیجه

مراجع اولیه API، فرهنگ داده و قراردادهای پیام در سطح مستندات ایجاد شدند. برای حفظ صحت، هر سند همراه با مسیر منبع کد/DDL قابل ردیابی است و موضوعات فاقد مرجع رسمی به‌عنوان محدودیت باقی مانده‌اند.


## پالایش ساختار پروژه پس از D04

در مرحله پاک‌سازی، فایل‌های Migration مستقل در یک اسکریپت واحد تجمیع شدند. خط مبنای پایگاه داده، اسکریپت تجمیعی تغییرات و Seed به‌صورت فایل‌های اجرایی SQL در پوشه `Database/` نگهداری می‌شوند. اسکریپت‌های راستی‌آزمایی SQL به `Tests/Database/` منتقل شده‌اند.
