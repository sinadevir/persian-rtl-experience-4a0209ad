# گزارش پالایش ساختار پروژه نسخه 11.8

## هدف

کاهش فایل‌های همراه پروژه بدون حذف کد اجرایی، تست‌های کدنویسی‌شده یا مستندات مرجع تولیدشده در مراحل D01 تا D04.

## ساختار نگه‌داری‌شده

- کدهای اجرایی در پوشه‌های `Application/`، `Domain/`، `Endpoints/`، `Infrastructure/`، `Middleware/` و `Modules/` حفظ شدند.
- پروژه آزمون واحد `Tests/PropertyDomain.UnitTests/` حفظ شد.
- مستندات مرجع D01 تا D04 و README هفت ماژول حفظ شدند.
- فایل تنظیمات و فایل پروژه حفظ شدند.

## تجمیع پایگاه داده

فایل‌های مستقل Migration در یک فایل اجرایی واحد تجمیع شدند:

- `Database/PropertyDomain-Baseline.sql`: ایجاد ساختار پایه برای پایگاه داده جدید.
- `Database/PropertyDomain-Migrations.sql`: تجمیع ۲۰ تغییر افزایشی قبلی با ترتیب وابستگی.
- `Database/Seeds/UsageClassification.sql`: داده اولیه طبقه‌بندی کاربری؛ از Migrationها جدا نگه داشته شده است.
- `Tests/Database/`: اسکریپت‌های SQL راستی‌آزمایی؛ این فایل‌ها Migration نیستند.

یک فایل با نام `20261115_B01_PartyIdentityAndContactVerification.sql` در پوشه قبلی Migration قرار داشت، اما محتوای آن صرفاً پرس‌وجوهای راستی‌آزمایی بود؛ بنابراین به `Tests/Database/` منتقل شد و در شمار ۲۰ Migration تجمیع‌شده نیست.

## فایل‌های حذف‌شده

گزارش‌های تاریخی Iteration، یادداشت‌های بازبینی، برنامه‌ریزی Sprint، برنامه‌های آزمون متنی، منابع اولیه، راهنمای استاندارد قدیمی، فایل موجودی JSON، راهنمای رویدادهای قدیمی و README ریشه قدیمی حذف شدند. محتوای مرجع نهایی ماژول‌ها و مستندات D01 تا D04 جایگزین نیاز به نگه‌داری آن مجموعه‌های تکراری/تاریخی هستند.

## ملاحظات ایمنی پایگاه داده

- اسکریپت Baseline برای ساخت پایگاه داده خالی است و نباید روی پایگاه داده دارای داده اجرا شود.
- برای ساخت پایگاه داده جدید، ابتدا Baseline و سپس اسکریپت تجمیعی Migration اجرا شود.
- برای پایگاه داده موجود، فقط پس از شناسایی نسخه و وضعیت اشیا، تهیه نسخه پشتیبان و بازبینی پیش‌شرط‌ها، اسکریپت Migration اجرا شود.
- هیچ اسکریپت SQL در این مرحله اجرا نشده و صحت اجرایی تجمیع با SQL Server تأیید نشده است.
