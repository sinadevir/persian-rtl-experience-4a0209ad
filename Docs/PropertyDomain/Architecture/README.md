# مستندات معماری

این پوشه مرجع مستندات معماری نسخه 11.8 پروژه `PropertyDomain.WebApi` است.

## اسناد

| سند | موضوع | وضعیت |
|---|---|---|
| [معماری کلان سامانه](./01-معماری-کلان-سامانه.md) | سبک معماری، مرز ماژول‌ها، لایه‌ها، وابستگی‌ها، داده، امنیت، رویدادها و جریان‌های اصلی | تهیه‌شده در مرحله D02؛ مبتنی بر کد نسخه 11.8 |

## قواعد نگهداری

1. توضیحات این پوشه باید فارسی باشند؛ نام فنی کلاس‌ها، متدها، جدول‌ها، مسیرها و شناسه‌ها عین کد حفظ شوند.
2. هر ادعای مربوط به رفتار اجرایی باید به کد یا قرارداد معتبر نسخه جاری قابل ردیابی باشد.
3. قابلیت طراحی‌شده ولی پیاده‌سازی‌نشده نباید در نمودارها یا متن به‌عنوان قابلیت فعال نمایش داده شود.
4. تصمیم دامنه‌ای که منبع رسمی ندارد باید با برچسب «نیازمند تصمیم رسمی» مشخص شود.
5. تغییر معماری باید همراه با به‌روزرسانی این سند و ثبت اثر آن بر ماژول‌ها، API، داده و رویدادها باشد.
